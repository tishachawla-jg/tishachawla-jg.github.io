Building

Open-source infrastructure for running agents reliably, co-created and built in the open under The Agent Plane.

  • TokenOps
    50 ★Pythonpip install agent-tokenops

    Run-aware token governance for multi-agent systems. Enforces one budget across a whole workflow rather than per call, so a runaway agent stops before the invoice arrives.

    Featured in Microsoft's Command Line PyPI
  • Chronicle
    20 ★Python

    Record-and-replay for agent decision graphs. Turns a production agent failure into a committed regression test, then re-runs your fix without live model calls.
